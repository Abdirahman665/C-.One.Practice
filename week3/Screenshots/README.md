=====The if-else Statement

An if-else statement will execute one block of statement if its Boolean
expression is true or another block if its Boolean expression is false

It has two parts: an if clause and an else clause

In

--a generic format looks like this:--

if
(expression)

{

statements

}

else

{

statements

}



----Nested Decision Structures

You can create nested decision structures to test more than one condition.

-------Nested means “one inside another"

if (expression)

{

if (expression)

{

statements

}

else

{

statements

}

}

else

{

statements

}
